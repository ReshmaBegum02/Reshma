# 📊 Exploratory Data Analysis (EDA) Project

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on sales data to identify trends, missing values, and revenue patterns.

## 📊 Objectives
- Data Cleaning
- Handling Missing Values
- Data Visualization
- Finding Key Insights

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Key Insights
- Sales increased in Q4
- Missing values mostly in Age column
- Category A has highest revenue
